# КиноКино — промосайт

Одноэкранная страница в стилистике Telegram-приложения: графитовый фон, коралловый акцент, логотип, заголовок, короткое объяснение и одна кнопка перехода в Telegram. HTML + CSS, без фреймворка, клиентского JavaScript, сторонних шрифтов, трекеров и зависимостей. Кнопка открывает `https://t.me/MovieDuoBot?startapp`, как в исходном приложении.

## Локальный просмотр

Из этой папки:

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Открыть http://127.0.0.1:4173. Страница использует абсолютные пути от корня; открывать через HTTP, не через `file://`.

## Проверка и сборка

Node.js 20+; установка пакетов не нужна.

```sh
npm run check
SITE_URL=https://your-domain.by npm run build
```

Замените адрес на реальный финальный домен. Сборка намеренно не запускается без него: нельзя публиковать canonical или sitemap с выдуманным адресом. Скрипт добавляет canonical, og:url, абсолютную ссылку на изображение для соцсетей, robots.txt и sitemap.xml. На хостинг загружать содержимое `dist/`. Развёртывание в подпапку не поддерживается.

`_headers` подходит для Cloudflare Pages и Netlify. При другом хостинге перенесите заголовки в его конфигурацию. Настройте настоящий HTTP 404 для отсутствующих страниц, не перенаправляйте все URL на главную. HTTPS и редирект на единственный вариант домена настройте на хостинге.

## Индексация и поиск

- Основное намерение: «что посмотреть вдвоём», «как выбрать фильм вдвоём», «выбор фильма в Telegram». Страница коротко описывает назначение приложения.
- Весь текст доступен в исходном HTML без рендеринга JavaScript.
- Есть уникальные title/description, один H1, Open Graph и SoftwareApplication JSON-LD без выдуманных оценок или отзывов.
- `robots.txt` разрешает обход всем поисковым роботам. На уровне хостинга/WAF также нельзя блокировать Googlebot, Bingbot и поисковые ИИ-краулеры (например, OAI-SearchBot). Не включайте обязательную CAPTCHA для всех посетителей.
- До подключения домена canonical и sitemap не создаются. После публикации: проверить HTTPS/200, robots/sitemap/canonical, добавить сайт в Google Search Console, Яндекс Вебмастер и Bing Webmaster Tools, отправить sitemap.
- Публичные тестовые копии закрывайте от индексации заголовком `X-Robots-Tag: noindex`, не изменяя robots основного сайта.
- Для оценки результата подключите измерение переходов в Telegram и сравнивайте их с фактическими запусками/созданием комнат в приложении. Сейчас аналитика не установлена и переходы не приписываются рекламным кампаниям.
- Следующие страницы стоит добавлять по реальным вопросам и данным поиска. Каждая должна содержать самостоятельную пользу. Дубли под похожие ключевые слова не нужны.

Ни первое место, ни включение в ИИ-ответы не гарантируются. Техническая доступность — основа; дальше нужны индексация, полезный контент, упоминания и наблюдение за реальными запросами.

Официальные рекомендации: [Google: AI features and your website](https://developers.google.com/search/docs/appearance/ai-features), [OpenAI: bots](https://platform.openai.com/docs/bots).
